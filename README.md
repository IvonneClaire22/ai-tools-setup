# ai-tools-setup
Setup task using Cursor IDE, Claude Code, Codex, and GitHub

# 100Hires Trial Task

## Tools Installed
- Cursor IDE
- Claude Code extension
- Codex extension
- GitHub
- Git

## Steps Completed
1. Visited the Cursor website: https://cursor.com/
2. Downloaded and installed Cursor IDE
3. Read and accepted the Terms and Conditions
4. Created a Cursor account
5. Logged into Cursor IDE
6. Opened the Extensions panel using `Ctrl + Shift + X`
7. Searched for the Claude Code extension
8. Installed the Claude Code extension
9. Searched for the Codex extension
10. Installed the Codex extension
11. Opened GitHub in Chrome
12. Created a public GitHub repository named `ai-tools-setup`
13. Clicked the green `Code` button
14. Copied the HTTPS repository link
15. Opened the repository in Cursor by:
    - Clicking `Clone Repository`
    - Pasting the HTTPS repository link
16. Created the `README.md` file
17. Committed and pushed the files to GitHub using the agent in the cursor

## Issues Encountered

### Issue 1: Git was not recognized in the terminal
**Solution:**  
Installed Git, added Git to the system PATH, and restarted Cursor IDE.
